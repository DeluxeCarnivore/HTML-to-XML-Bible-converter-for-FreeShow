What this handles

Expects the "<!-- Source N: NN_bookname.htm -->" style export: a comment marks each book, <h4> marks each chapter, and each verse is a <p> starting with <sup>N</sup>.

It also works around five real data quirks found across several such files:

  • Malformed <pb> tags that silently swallow later chapters
  • A stray unclosed <font> right after a chapter heading, with the same effect
  • A verse's leading <sup> nested inside a wrapper tag, which can merge several verses into one
  • Genuinely empty red-letter spans (a verse folded into its neighbor)
  • Doubly-wrapped red-letter spans, which would otherwise produce broken nested tags

The OSIS output also works around two quirks in how FreeShow itself parses red-letter text (an invisible padding character so an all-red verse isn't dropped, and non-breaking spaces so words don't run together between two red spans) — both confirmed against FreeShow's own source.

How To Download Bible HTML

Steps:

  • Download a book from ph4.
  • Merge all HTML files using Merge HTML Files Online.
  • Drag the merged HTML file here.
  • Choose Zefania or OSIS.
  • Click Convert.
